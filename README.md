# Rule-Based AI Chatbot

## Project Title

Rule-Based AI Chatbot

## Description

This project is a simple rule-based Artificial Intelligence chatbot developed using Python.

The chatbot interacts with the user through predefined responses and uses if-else decision-making logic to identify different types of user input.

It can handle greetings, basic questions, questions about Artificial Intelligence, thank-you messages, and exit commands.

The chatbot runs continuously using a while loop until the user enters an exit command.

## Features

- Handles greetings such as hello, hi, and hey
- Responds to questions about its name
- Explains what it can do
- Provides a basic explanation of Artificial Intelligence
- Handles thank-you messages
- Handles exit commands such as bye, exit, and quit
- Provides a default response for unknown inputs
- Uses if-else decision-making
- Uses a continuous interaction loop

## Technologies Used

- Python
- Visual Studio Code
